# Product Requirements Document (PRD)

**Project:** Novadines Portfolio & Agency Landing Page
**Target Audience:** B2B Hospitality (Restaurant Owners, Lounge Managers, Directors)
**Objective:** A high-conversion landing page demonstrating the speed and premium feel of Novadines digital menus, driving users to initiate contact via WhatsApp.

---

## 1. Core Value Proposition (Business Logic)
- **Zero Friction:** No app downloads; instant QR access.
- **Zero Commissions:** Built-in WhatsApp ordering to bypass 30% delivery app fees.
- **Premium Aesthetics:** High-resolution layouts that elevate the restaurant's brand.

---

## 2. Feature Matrix (MoSCoW)

### Must-Have (V1 Launch)
- **Direct-to-WhatsApp Flow:** All primary CTAs must route the user to a pre-filled WhatsApp message.
- **Live Demo iframe:** An interactive mockup allowing users to test a real client menu (e.g., Oasis Lounge) without leaving the page.
- **Interactive QR Code:** A visible QR code on desktop views so users can scan and test the mobile experience instantly.
- **Bilingual Support Architecture:** Foundation for English/Arabic toggling (UI text).

### Should-Have (V1.5)
- **Analytics Tracking:** UTM parameter tracking on WhatsApp links to measure campaign ROI.
- **Dine-in vs. Takeaway Toggles:** Interactive tabs in the demo section.

### Won't-Have (Currently Excluded)
- **AR Models (Coming Soon):** 3D photorealistic on-table rendering is strictly excluded from current implementation and marked as a future tier.

---

## 3. User Conversion Flows

### Flow A: The Direct Inquiry (High Intent)
1. User lands on Hero Section.
2. User clicks "Request a Build".
3. **Action:** Opens WhatsApp Web / Mobile App.
4. **Data:** Pre-filled message: *"Hi Novadines, I want to turn my menu into a revenue engine. Can we discuss a build?"*

### Flow B: The Skeptic (Requires Proof)
1. User scrolls past Hero to the "Problem vs. Solution" section.
2. User reaches the Live Demo section.
3. User interacts with the iframe or scans the QR code.
4. User validates the speed and UI.
5. User clicks "Get This For My Restaurant" below the demo.
6. **Action:** Opens WhatsApp with pre-filled message: *"Hi Novadines, I just tried the Oasis Lounge demo. I want this for my venue."*

---

## 4. Key Page Sections (Content Strategy)

1.  **Hero Section:** 
    - Headline: "Turn Your Digital Menu Into a Revenue Engine."
    - Visual: A floating, premium Wagyu Steak (glow effect, NO AR tags).
2.  **Problem vs. Solution:** 
    - "The Old Way" (PDFs, 30% fees) vs. "The New Way" (Web Apps, 0% fees).
3.  **Services & Tiers:** 
    - Tier 1: The Foundation (Custom UI, Cloud Hosting).
    - Tier 2: The Conversion Engine (WhatsApp Cart).
    - Tier 3: The AR Experience (Clearly marked "Coming Soon").
4.  **Live Demo:** Interactive iPhone mockup & QR Code.
5.  **About/Founders:** Huzaifa Siddiqui (Technical Director) & Owais Siddiqui (Head of Infrastructure) profiles to build engineering trust.
6.  **Footer:** Contact information, Social Links, and final WhatsApp CTA.
